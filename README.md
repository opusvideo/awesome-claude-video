## What is verified

- The original post is readable, has a video attachment, and reports strictly more than 10,000 views. Reposts and prompt replies are not counted as separate videos.
- Model use, timing and cost remain creator claims. We have not independently reproduced the works or fully fact-checked educational content or model comparisons.
- “Prompt / brief” may be a short creative request rather than a complete prompt. Missing prompts and code are marked explicitly. Some titles are editorial descriptions.
- Comparisons have their own category. Other tools and models are listed where identified in creator posts, source code or briefs. Each category is sorted by views, not by a quality score.
